[打开静音动画学习](https://fsy132.github.io/learning/) · [阅读范围](https://fsy132.github.io/learning/coverage.html)

这是公开作品集的网站发布仓库。网站保留13个学习模块、188个问题页：左侧固定画面静音循环，右侧误区、步骤、结论，以及需要时展开的公式符号和代入。后续也可以加入其他作品。

## 添加作品

在 `content/projects.json` 数组中添加一项，填写标题、简介、年份、封面和站内详情页地址。图片放在 `assets/`，项目页面放在独立目录。现有硬件学习页位于 `learning/`。

## 发布方式

GitHub Pages 使用 `main` 分支的根目录。提交并推送后由GitHub自动发布；`.nojekyll` 表示直接使用现有静态文件，无需安装构建工具。站内相对链接可在同一域名正常运行。

`downloads/offline-learning.html` 是可以单独保存并离线打开的当前课程。22段MP4及其合集是早期独立基础示意，并非当前188页的完整视频版。

## 阅读范围与来源

已核对作者公开主页91条作品目录，其中实际为16条视频、1篇长文、74条图文。16条视频采用全时间轴抽样和关键帧细读，另读取1篇长文；并非连续逐帧观看，74条图文尚未逐篇整理。页面区分原片观点、条件修正和独立教学补充。

网站动画与解读为独立重写。本仓库仅包含公开网站文件，不含原作者视频、原始截图、账户凭据或私人审阅档案。
